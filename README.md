# 🛵 Grab Rider — 3D 배달 러너

그랩(Grab) 배달 라이더 컨셉의 3D 러너 게임입니다. 그린 재킷과 배달 박스를 단 라이더가 도로 위 자동차들 사이를 비집고 달립니다.
메뉴·HUD·팝업은 배달 앱처럼 그린 헤더 + 흰 카드 + 하단 시트 스타일로 구성했습니다.
모바일(터치)과 PC(키보드) 둘 다 지원하며, 브라우저만 있으면 설치 없이 바로 플레이할 수 있습니다.

## 실행 방법

ES 모듈을 사용하므로 `file://`로 직접 열지 말고 정적 웹 서버로 띄워야 합니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- 같은 Wi-Fi의 휴대폰에서 `http://<PC의 IP>:8000`으로 접속하면 모바일에서 테스트할 수 있습니다.
- GitHub Pages 등 아무 정적 호스팅에 그대로 올려도 동작합니다 (빌드 과정 없음).
- Three.js는 `vendor/`에 포함되어 있어 오프라인에서도 실행됩니다.

| 동작 | 키보드 | 터치 |

## 재미 요소

- **니어미스 & 콤보** — 차 옆을 아슬아슬하게 스치면 보너스. 0.35m 이내는 *PERFECT* (2배). 3초 안에 연속으로 성공하면 콤보 배율이 올라갑니다.
- **역주행 차선** — 중앙선 왼쪽 반대 차선으로 달리면 점수 2배 + 니트로 충전. 대신 차가 정면으로 달려오고 경적을 울립니다.
- **니트로** — 니어미스/코인으로 게이지를 채워 발동. 4초간 최고속도 135%, 무적, 부딪힌 차는 날려버리고 *SMASH* 보너스.
- **파워업** — 🛡️ 실드(충돌 1회 방어), 🧲 자석(코인 흡수), ✨ 점수 x2, ⏳ 슬로우모션.
- **다양한 교통** — 승용차, SUV, 택시, 트럭, 버스, 사이렌 켠 경찰차(니어미스 2배). 깜빡이를 켠 차는 곧 차선을 바꿉니다. 차선 경계 위 라바콘 주의!
- **낮/노을/밤 사이클과 비** — 거리에 따라 시간대가 바뀌고, 밤에는 헤드라이트와 가로등이 켜집니다. 비가 오면 미끄럽지만 점수 1.3배.
- **점점 어려워지는 난이도** — 달릴수록 속도와 교통량, 차선 변경 빈도가 증가합니다.
- **코인 & 차고** — 코인으로 더 빠르고 핸들링이 좋은 바이크 5종을 구매. 빠른 바이크일수록 점수가 빨리 오릅니다.
- **미션** — 항상 3개의 미션이 주어지며, 달성 시 코인 보상 후 다음 판에 더 어려운 미션으로 교체됩니다.
- **이어달리기** — 충돌 후 코인 150개로 한 판에 한 번 부활.
- **출석 보상** — 하루 한 번 접속하면 코인 100개.
- **랭킹** — TOP 10 점수 랭킹 (이름 등록). 데이터는 브라우저 `localStorage`에 저장됩니다.

## 파일 구조

```
index.html            화면/HUD 마크업
css/style.css         UI 스타일 (모바일 세이프 영역 대응)
js/main.js            게임 루프, 입력, 교통/코인/파워업, UI 흐름
js/models.js          로우폴리 3D 모델(바이크·자동차·소품)과 캔버스 텍스처
js/audio.js           WebAudio 합성 효과음/엔진음 (음원 파일 없음)
js/storage.js         저장 데이터, 바이크 목록, 랭킹, 미션
vendor/               Three.js r160 (MIT)
```

## 참고

- 랭킹은 기기(브라우저)별 로컬 랭킹입니다. 여러 사람이 함께 겨루는 온라인 랭킹이 필요하면 별도 백엔드(예: Firebase, Supabase)를 연결해야 합니다.
- URL에 `?debug`를 붙이면 콘솔에서 `window.__G`로 게임 상태를 확인할 수 있습니다.
- "Grab"은 Grab Holdings의 상표입니다. 개인 학습/팬 프로젝트 용도로 쓰고, 공개 배포·스토어 출시 시에는 `index.html`, `manifest.webmanifest`의 이름을 자체 브랜드로 바꾸세요.
