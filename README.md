# 🛵 Grub Rider — 3D 배달 러너

배달 라이더 컨셉의 3D 러너 게임 **Grub Rider** 입니다. 그린 재킷과 배달 박스를 단 라이더가 도로 위 자동차들 사이를 비집고 달립니다.
메뉴·HUD·팝업은 배달 앱처럼 그린 헤더 + 흰 카드 + 하단 시트 스타일로 구성했습니다.
모바일(터치)과 PC(키보드) 둘 다 지원하며, 브라우저만 있으면 설치 없이 바로 플레이할 수 있습니다.

## 실행 방법

ES 모듈을 사용하므로 `file://`로 직접 열지 말고 정적 웹 서버로 띄워야 합니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

- 같은 Wi-Fi의 휴대폰에서 `http://<PC의 IP>:8000`으로 접속하면 모바일에서 테스트할 수 있습니다.
- GitHub Pages 등 아무 정적 호스팅에 그대로 올려도 동작합니다 (빌드 과정 없음).
- Three.js는 `vendor/`에 포함되어 있어 오프라인에서도 실행됩니다.

## 시작 화면

밝은 배달 앱 스타일: 그린 헤더(브랜드·코인·계정) + *DELIVERING IN* 국가 주소 바, 가운데 창에는 라이더 뒤쪽 위에서 앞 거리를 보는 3D 장면(차 없이, 건물이 카메라 뒤로 사라지지 않는 방향),
아래 흰 시트에 최고 점수·최고 거리·국가, **START RIDE** 버튼, 1V1 프로모 카드, 원형 서비스 아이콘(차고·랭킹·미션·설정).

## 조작법

설정의 **CONTROLS** 로 3가지 중 선택합니다.

| 방식 | 조향 | 가속 / 브레이크 |
| --- | --- | --- |
| **ONE-HAND**(기본) | **조이스틱 하나**: 화면 아무 데나 누르면 그 자리에 조이스틱이 생기고 좌우로 밀면 조향 | 같은 조이스틱을 **위로 GAS, 아래로 BRAKE** (버튼 없음, 손 떼면 오른쪽 아래에 반투명 조이스틱 표시) |
| **SLIDE + PEDALS** | 조향 쪽 화면에서 좌우 슬라이드 | 반대쪽 THROTTLE(최고속 가속) / BRAKE |
| **ARROWS + PEDALS** | ◀ ▶ 버튼 | 반대쪽 THROTTLE / BRAKE |

- 방향 버튼·키보드 조향은 누르면 부드럽게 차오르고 최대치를 80% 로 낮춰 감도를 완화했습니다.
- 키보드: ← → / A D 조향, ↑ / W 가속, ↓ / S 브레이크, P / Esc 일시정지, Enter 시작·재시작.
- 공중 묘기: 슬라이드 중이면 손가락을 위·아래(플립)·옆(스핀)·대각선(메가 플립)으로 밀기. 페달 방식은 페달도 함께 사용.
- **FLIP CONTROL LAYOUT**(페달 방식에서만): 조향 쪽과 페달 쪽 좌우를 바꿉니다.
- 플레이 화면 HUD 는 배경 상자 없이 글자·아이콘만 표시하고, 켜진 아이템·부스터는 속도계 아래에 **이름 + 남은 초 + 줄어드는 막대**로 보입니다.

## 소모성 부스트

- 메뉴 **BOOSTS** 줄: 보유 중이면 탭해서 다음 판에 장착(체크), 없으면 두 번 탭해서 코인으로 구매 후 바로 장착.
- 판 시작 시 장착한 부스트를 1개씩 소모. 남은 개수가 있으면 다음 판에도 장착 유지.

| 부스트 | 효과 | 가격 |
| --- | --- | --- |
| SHIELD | 충돌 1회 막는 보호막으로 출발 | 400 |
| HEAD START | 출발 직후 5초간 최고속도 1.5배 질주 + 무적 + 코인 자석 (배기 불꽃) | 400 |
| x2 SCORE 30s | 처음 30초 점수 2배 | 500 |
| GIANT START | 거대 모드로 출발 | 600 |
| SECOND CHANCE | 크래시 후 1회 무료 부활 (이어달리기 기회와 별개) | 1,000 |

- 코인 상점 하단 **BOOST BUNDLES**: 5개 묶음을 4개 가격에. 설정은 `js/config.js` 의 `BOOSTS`, `BOOST_BUNDLE`.

## 국가 순서

매 판 시작 국가와 국가 순서가 무작위로 섞입니다(판 시드 기반이라 챌린지 링크로 들어오면 같은 순서). 메뉴에서 보던 나라에서 그대로 출발합니다.

## UI · 사운드

- 게임 UI는 글로벌 영문(`NEAR MISS!`, `WRONG WAY x2`, `DELIVERY RECEIPT`, `CRASHED!` / `DELIVERED!` 등)과 미니멀 라인 아이콘(`js/icons.js`)을 사용합니다.
  결과 화면은 신기록 시 `DELIVERED!`, 그 외 `CRASHED!` 입니다.
- 엔진음은 이전 대비 약 37% 볼륨, 128 BPM 합성 BGM(킥·클랩·하이햇·베이스·아르페지오)이 깔리며 속도가 오를수록 비트가 촘촘해집니다.
- 설정: SOUND FX / MUSIC / VIBRATION / GRAPHICS / **SCREEN WET EFFECT** / THROTTLE / TOUCH STEERING / **FLIP CONTROL LAYOUT** / MY COUNTRY.

## 재미 요소

- **니어미스 & 콤보** — 차 옆을 아슬아슬하게 스치면 보너스. 0.35m 이내는 *PERFECT* (2배). 3초 안에 연속 성공하면 콤보 배율 상승.
- **좌/우측 통행** — 싱가포르·말레이시아·인도네시아·태국은 **좌측통행**(같은 방향 차선이 왼쪽, 마주 오는 차가 오른쪽), 베트남·필리핀·캄보디아·미얀마는 **우측통행**.
  국경 게이트에 *KEEP LEFT / KEEP RIGHT* 안내판이 있습니다. 차량은 **절대 중앙선을 넘지 않으며**(자기 쪽 차선에 고정),
  통행 방향이 바뀌는 국경 앞 200m ~ 뒤 150m 에는 차를 만들지 않고, 다른 규칙 구역으로 들어가는 차는 라이더에게서 40m 이상 떨어져 있을 때 정리합니다.
- **역주행 차선** — 그 나라 기준 반대 차선을 달리면 점수 2배.
- **점프 & 공중 묘기** — 경사판 견인트럭(600m 이후 자주)과 도로 곳곳의 **독립 점프대**(황금색 네온 안내선, 180~320m마다)를 타면 공중으로 뜹니다(`isAirborne`).
  공중 조작: 스로틀/브레이크(위/아래) = **앞뒤 플립(Pitch)**, 좌우 = **옆으로 도는 360 스핀(Yaw)**, 사선으로 계속 누르면 그 **대각선 축으로 360°** 회전합니다
  (공중 자세를 쿼터니언으로 관리해 입력 방향을 회전축으로 사용, 한 손 조작 중엔 손가락을 민 방향 그대로). 회전수(`rotationCount`)가 쌓입니다.
  수평으로 착지하면 회전 종류별 차등 점수(1바퀴당): **FLIP +500**, **360 SPIN +1,200**, **DIAGONAL MEGA FLIP +3,000**(다축, 많이 돈 축 기준), 회전 없음 +200.
  착지하는 순간 **1.8초 무적**(보호막 + 은은한 점멸): 착지 지점의 차량·장애물과 부딪혀도 통과합니다.
  **착지 보조**: 땅에 닿기 0.25초 전부터 수평과의 각도가 40° 안이면 바퀴가 바닥을 향하도록 자동으로 돌려 줍니다(여러 축으로 돌려도 착지가 쉬움, 거의 뒤집힌 채 내려오면 크래시).
  회전이 덜 끝났거나 뒤집힌 각도(수평에서 약 39° 이상)로 닿으면 **CRASH LANDING**으로 게임 오버. 입력을 놓으면 가까운 수평 자세로 살짝 맞춰 줍니다.
- **스콜(Squall)** — 30초 폭우 이벤트(점수 1.3배, 빗소리·주기적 천둥 번개). 화면에 맺힌 빗물이 중력 방향으로만 흘러내리며 잔상과 굴절을 남깁니다(`js/rainfx.js`, Canvas 2D).
  저사양 기기는 설정에서 *SCREEN WET EFFECT* 를 끄면 되고, 이때도 어두워지는 조명·번개 플래시·하늘을 비추는 물웅덩이로 폭우가 표현됩니다. 물웅덩이를 밟으면 핸들이 둔해지고 미끄러집니다.
- **위험 요소** — 갓길 노점상(Kaki Lima 수레·천막), 중앙선 라바콘·공사 표지판,
  **깜빡이를 켜고 1초 뒤 부드럽게(S자, 차체가 살짝 틀어지며 1.5초) 차선을 바꾸는 차량**(앞서가는 같은 방향 차량이 특히 자주),
  **도로 돌발 요소**: 공사 포트홀(덜컹 + 감속, 콤보 끊김), 열린 맨홀(충돌), 떨어진 화물 상자(충돌, 거대화로 날려버림).
- **DROP ZONE** — 도로 가장자리의 반투명 초록 구역을 정확히 통과하면 +50 코인.
- **파워업** (100~150m마다) — 보호막, 코인 자석, **거대화(GIANT MODE: 6초간 1.8배 크기·무적·부딪힌 차 날려버림)**, 점수 x2, 슬로우모션.
- **국가 구간** — 1,000m마다 나라가 바뀝니다(동남아 8개국, 판마다 시작 국가·순서 무작위, `js/themes.js`). 한국·일본·미국·프랑스 맵은 [`archive/`](archive/) 폴더에 보관만 하고 스폰하지 않습니다.

  | 나라 | 랜드마크 | 거리 특색 |
  | --- | --- | --- |
  | 싱가포르 (마리나 베이) | 마리나 베이 샌즈 + 슈퍼트리 + 아트사이언스 연꽃 | 페라나칸 숍하우스·미래형 타워, 레인트리 가로수, 택시 |

  | 태국 (방콕) | 왓 아룬 (도자기 장식 프랑) | 네온·식민지풍, 프랑지파니, 노랑 깃발 줄, 툭툭 |

  나라마다 교통도 다릅니다: 싱가포르 2층 버스·블루/옐로 택시, 말레이시아 빨강·흰 택시, 인도네시아 앙콧(합승 미니밴)·파란 바자이·블루 택시,
  태국 핑크·연두 택시·툭툭·송태우(픽업 합승), 베트남 오토바이 물결·초록 택시·노랑 버스, 필리핀 지프니·트라이시클(사이드카),
  캄보디아 레모크(오토바이 객차), 미얀마 트라이쇼(자전거 인력거)·흰 택시·파란 버스. 일반 차 색도 나라별 팔레트.
  나라마다 건물 양식(Ruko·튜브하우스·네온·고층·브라운스톤·오스만), 가로수(야자·벚꽃·은행·활엽), 노점·자판기·카페, 원경 랜드마크, 특수 교통(툭툭·스쿠터 떼·옐로캡)이 다릅니다.

- **3D 광고판** — 나라별 패러디 포스터(`js/config.js` 의 `BILLBOARD_POSTERS`) + 대형 LED 전광판 **CURRENT COUNTRY #1: 닉네임 (거리m)** — 지금 달리는 나라의 1위 점수·국기 배지와 그 라이더가 착용한 바이크·의상 3D 스냅샷.

  **공용 아이템**: 헤드기어 — 두리안, 오리 프로펠러, CRT 뚱뚱이 TV / 배달통 — 피자 상자 타워, 미니 냉장고, 스티로폼 생선 박스, 붐박스, 리본 선물 상자, 부스터 가스 캡슐,
  대나무 찜통(반투명 김), 테이프 택배 박스, 고양이 아파트 박스, 순금 금괴, 투명 어항(유리 재질), 아이스크림 상자.
  시작 화면(컴팩트): 위에는 로고 글자 + 코인·계정 한 줄만 투명하게 떠 있고, 차고·랭킹·미션·설정은 오른쪽 세로 원형 버튼, 아래 시트는 부스트 5칸 + START RIDE(버튼 안에 BEST 거리 | RECENT 직전 판 거리)만 (가로 화면에선 시트가 오른쪽에 떠서 라이더가 가려지지 않음).
  주행 중 알림은 최대 2개만 (같은 알림은 xN 으로 합침, 이전 알림은 작게 흐려짐). 피버 잔상은 바이크 뒤 노면에 깔리는 무지개 빛줄기라 점프 중에도 바이크를 가리지 않습니다.
  차고에서 아래로 스크롤해도 위쪽 3D 미리보기와 구매 버튼이 고정되어 입혀 보는 모습이 계속 보입니다.
  **PAINT 탭**: 단색(무광)·메탈릭(환경 반사 금속 재질)·네온(발광 + 후광) 17색 — 한 번 사면 바이크와 헤드기어 둘 다에 칠할 수 있습니다. **MYSTERY BOX**(4,000 코인) 가챠: 등급을 먼저 뽑고(COMMON 60 / RARE 30 / EPIC 9 / LEGENDARY 1%) 그 등급의 미보유 상자·의상·헬멧 하나(국기 제외), 전부 보유 시 1,600 코인 환급.
- **FLAGS 탭 (상점 국기)** — 46개국 국기(주행 테마 8개국 10,000 / 그 외 8,000 코인, `FLAG_SHOP_CODES`). 헬멧 스티커·차체 데칼·배달 상자 깃발로 붙고, *No Flag* 로 뗄 수 있습니다.
  국기는 모두 **실제 국기 이미지**(`assets/flags/XX.svg`, [country-flag-icons](https://github.com/catamphetamine/country-flag-icons) MIT)를 씁니다.
- **국가대표 패키지 (국가 1위 전용)** — 구매 불가. 내 국가 랭킹 **실시간 1위**가 되는 즉시 **국가대표 바이크**(슈퍼바이크, 최고 320 km/h, 아래 참고)와
  **국가대표 배달통**(에어로 포드, 아래 참고)이 함께 지급·자동 장착됩니다. 국기 데칼은 FLAGS 탭에서 장착한 국기를 따릅니다(다른 나라 국기도, 국기 없음도 가능).
  국가대표 바이크는 두꺼운 타이어·골드 포크·브레이크 디스크의 무게감 있는 슈퍼바이크입니다. 동남아 8개국은 **나라 상징 동물의 머리가 프런트 페어링**이 되고,
  갈기·깃털 가닥이 탱크와 옆구리를 따라 뒤로 흐르며, 가운데는 기어·황동 배기관이 드러난 기계식 엔진, 뒤는 짧게 치켜 올라간 테일입니다(각진 로우폴리):
  싱가포르 MERLION RR(펄 화이트·레드 사자), 말레이시아 HARIMAU RR(오렌지·블랙 호랑이), 인도네시아 GARUDA RR(레드·골드 독수리), 태국 SIAM RR(아이보리·골드 흰 코끼리),
  베트남 RONG RR(레드·골드 용), 필리핀 MABUHAY RR(차콜 카라바오), 캄보디아 ANGKOR RR(사암·골드 나가), 미얀마 GOLDEN RR(에메랄드·골드 공작). 탱크는 나라 래핑.
  그 외 나라는 슈퍼바이크 페어링 + 국기 래핑. 국가대표 바이크·배달통에는 #1 표시가 없고, 차체 옆 국기 스티커도 붙이지 않습니다.
  **국가대표 배달통**은 날렵한 에어로 포드(뒤로 솟은 쐐기형 + 리어 스포일러 + LED 테일 + 디퓨저)이고, 옆면에 나라별 아트와 NATIONAL TEAM 문구, 뒷면에 나라 문양 + 큰 국가 코드가 들어갑니다.
  2위 이하로 밀리는 순간 바이크와 배달통이 함께 회수되고 원래 장비로 돌아갑니다. 1위 여부는 클라이언트 값이 아니라 DB 함수 `my_rank_v4` 로만 판단하며,
  30초마다(`FLAG_CHECK_INTERVAL_SEC`)와 앱 복귀·점수 전송·랭킹 조회 때 다시 확인합니다.
- **7일 연속 출석** (로그인 계정) — 200 → 300 → 400 → 600 → 800 → 1,000 → 1,500 코인, 7일차엔 한정 *Crown* 헬멧. 하루 빠지면 1일차부터.
- **미션 / 이어달리기** — 한 판 미션 3개, 코인 150개로 부활.
- **일시정지 = 배달 주문서** — 영수증 스타일로 주행 기록과 미션 진행률(%)을 보여줍니다.

## 안드로이드 앱 (Capacitor)

- 같은 웹 코드를 Capacitor 로 감싼 앱입니다(`android/` 폴더, 앱 ID `com.jdh0309032.grubrider` — 스토어 첫 업로드 후에는 바꿀 수 없음).
- **자동 빌드**: 푸시할 때마다 GitHub Actions(`Android build`)가 앱을 만들고, 실행 결과 페이지 아래 Artifacts 에 zip 으로 올립니다.
  - 서명 키 Secrets 가 없으면 `app-debug.apk`(테스트용). 폰에서 "출처를 알 수 없는 앱" 허용 후 설치.
    빌드마다 디버그 키가 달라 업데이트하려면 기존 앱을 지우고 설치해야 합니다.
  - 출시 서명 키를 Secrets 에 넣으면 `app-release.apk`(덮어쓰기 업데이트 가능) + `app-release.aab`(플레이 스토어 업로드용).
- **출시 서명 키 만들기** (한 번만, 내 컴퓨터에서. 파일·비밀번호는 잃어버리면 같은 앱으로 업데이트 불가 → 백업 필수, 저장소에 올리지 말 것):
  1. `keytool -genkeypair -v -keystore grubrider.keystore -alias grubrider -keyalg RSA -keysize 2048 -validity 10000`
  2. `base64 -w0 grubrider.keystore` 출력값을 저장소 Settings → Secrets and variables → Actions 에 `ANDROID_KEYSTORE_BASE64` 로,
     비밀번호·별칭을 `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS`(grubrider) / `ANDROID_KEY_PASSWORD` 로 등록
- 로컬 빌드: `npm install` → `npm run android:sync`(웹 파일을 `www/` 로 복사 후 동기화) → `npm run android:open`(Android Studio).
- 버전: `versionCode` = 빌드 번호(자동 증가), `versionName` = `1.0.<빌드 번호>`.

- `PAYMENTS.provider`
  - `'mock'`(기본): 테스트 결제 창 → 코인이 바로 들어옴(실제 돈 없음). **출시 빌드에서는 반드시 `'native'` 로 바꾸세요.**
  - `'native'`: Capacitor 앱 + RevenueCat(`@revenuecat/purchases-capacitor`) 으로 Google Play / App Store 결제. 웹에서는 상점이 비활성화됩니다.
- 실제 결제 흐름 (코인 위조 방지):
  1. 로그인 시 RevenueCat `app_user_id` = Supabase 사용자 ID
  2. 스토어 결제 → RevenueCat 이 영수증 검증 → 웹훅으로 Edge Function [`revenuecat-webhook`](supabase/functions/revenuecat-webhook/index.ts) 호출
  3. Edge Function(service_role)이 `credit_purchase` 로 `purchases` 원장에 기록(거래 ID 중복 지급 방지)하고 `pending_coins` 를 올림
  4. 게임이 `claim_pending_coins()` 로 받아 감(결제 직후 2초 간격 재시도, 로그인·앱 복귀 때도 확인)
- 설정 순서: Play Console / App Store Connect 에 소모성 상품 `grub_coins_s/m/l/xl` 등록 → RevenueCat 프로젝트에 연결 →
  `supabase functions deploy revenuecat-webhook --no-verify-jwt` → `supabase secrets set REVENUECAT_WEBHOOK_AUTH=<임의의 긴 값>` →
  RevenueCat 웹훅 URL `https://<프로젝트>.supabase.co/functions/v1/revenuecat-webhook`, Authorization 헤더에 같은 값 →
  `js/config.js` 의 `revenuecatApiKeyAndroid/Ios`(공개 SDK 키) 입력.
- 미스터리 박스는 차고에 등급별 확률을 표시합니다(가챠 확률 공개 정책).
- 코인 팩 수량을 바꾸면 `revenuecat-webhook` 의 `PRODUCT_COINS` 도 같이 바꾸고 Edge Function 을 다시 배포해야 합니다.

## 계정 · 서버 저장 · 국가 랭킹 (Supabase)

게임 데이터(코인, 보유·장착 아이템, 최고 기록, 미션, 설정, 출석)는 **기기(localStorage)에 저장하지 않고 Supabase 서버**(`player_data`)에 저장합니다.
변경되면 0.3초 안에 묶어서 바로 전송하고, 앱 전환·종료 직전에도 한 번 더 저장합니다. 기기에는 **로그인 유지용 토큰만** 남습니다.
비로그인(게스트)은 메모리에서만 플레이하고 새로고침하면 진행이 사라집니다. 새 계정으로 처음 로그인하면 그때까지의 게스트 진행이 계정으로 옮겨집니다.

설정 방법 (가장 쉬운 방법: [`supabase/setup_all.sql`](supabase/setup_all.sql) 하나를 SQL Editor 에서 실행 — 아래 3·4단계 + admin 관리자 지정 + 007(결제·계정 삭제·점수 검증) + 008(운영 설정)이 모두 들어 있고 여러 번 실행해도 안전):

1. [Supabase](https://supabase.com) 프로젝트 생성
2. Authentication → Providers → Email 에서 **Confirm email 끄기** (아이디를 `아이디@grabrider.game` 가상 이메일로 가입시킴)
3. SQL Editor 에서 [`supabase/schema.sql`](supabase/schema.sql) 실행 (랭킹 테이블 기본 스키마)
4. 이어서 [`supabase/migrations/004_player_data_admin.sql`](supabase/migrations/004_player_data_admin.sql) 실행
   (002·003 내용 포함: `player_data` 테이블, `load_player_data`/`save_player_data`/`lock_country`/`submit_score_v4`/`my_rank_v4`, 예전 전송 함수 차단)
   그다음 [`supabase/migrations/005_admin_country.sql`](supabase/migrations/005_admin_country.sql) 실행 (관리자 국가 변경)
   그다음 [`supabase/migrations/006_look_sync.sql`](supabase/migrations/006_look_sync.sql) 실행 (장착을 바꿀 때마다 랭킹 행의 바이크·상자·의상·헤드기어·국기·페인트를 바로 갱신 — 랭킹 3D 미리보기·전광판 동기화)
   그다음 [`supabase/migrations/007_payments_compliance.sql`](supabase/migrations/007_payments_compliance.sql) 실행 (코인 결제 원장, 계정 삭제, 서버 점수 검증)
5. `js/config.js` 에 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 입력 (publishable/anon 키만 사용, service_role 키는 절대 넣지 마세요)

- **국가 고정:** 접속 시 IP Geolocation(`GEO_IP_ENDPOINTS`: country.is → geojs → ipapi.co)으로 국가를 판별하고, 로그인 계정은 처음 판별된 국가가
  서버(`player_data.country_code`)에 고정되어 이후 바꿀 수 없습니다(설정 화면은 표시만). 점수 전송 함수는 클라이언트가 보낸 값이 아니라 이 고정 국가로 기록합니다.
  IP 판별이 모두 실패하면 기기 시간대 추정값이 고정됩니다. 잘못 고정된 경우 Supabase 에서 `player_data.country_code` 를 직접 고치세요.
  IP 조회 시 사용자의 IP 가 해당 공개 서비스로 전달됩니다.
- 랭킹 화면은 탭 2개: **국가 리그**(내 국가 TOP 10, 1위 옆 국기) / **WORLD LEAGUE**(전 세계 TOP 10, 모든 플레이어 옆에 국기 + 국가 코드, 내 세계 순위).
  국가대표 혜택은 고정된 내 국가 리그 1위에만 적용됩니다.
  행을 누르면 그 라이더가 착용한 바이크·상자·의상·헤드기어·국기·페인트 조합이 위쪽 3D 뷰포트에 표시됩니다. 내 행은 지금 장착한 모습 그대로 보입니다.
- **관리자 모드:** `player_data.is_admin = true` 인 계정으로 로그인하면 *ADMIN MODE* 가 켜집니다(지정 SQL 은 004 파일 하단 참고).
  관리자는 설정의 *MY COUNTRY* 에서 국가를 마음대로 바꿀 수 있고(서버 저장은 [`005_admin_country.sql`](supabase/migrations/005_admin_country.sql) 의 `admin_set_country`),
  결과 화면의 **ADMIN REVIVE** 로 비용·광고 없이 몇 번이든 즉시 부활합니다.
  모든 바이크·상자·의상·헬멧·국기·국가대표 바이크를 구매 없이 장착할 수 있고(`allUnlocked`), 주행 기록은 **랭킹에 전송하지 않으며**
  서버 함수(`submit_score_v4`)도 관리자 계정의 기록을 거부합니다. `?debug` 로 열면 설정에 이번 접속에만 적용되는 ADMIN MODE 토글이 보입니다
  (`ADMIN_DEBUG_TOGGLE`, 이 토글 상태에서도 기록 전송 안 함).
- 코인·아이템은 클라이언트에서 계산해 저장하므로 조작을 완전히 막을 수는 없습니다(서버 함수에서 형식·범위만 검증).

## 참고

- 랭킹은 `js/config.js` 의 Supabase 설정을 사용합니다.
- URL에 `?debug`를 붙이면 콘솔에서 `window.__G`로 게임 상태를 확인할 수 있습니다.
- 게임 이름은 **Grub Rider** 입니다. 내부 저장 키(`grabrider.session.v1`)와 계정용 가상 이메일 도메인(`grabrider.game`)은 기존 계정 호환을 위해 그대로 둡니다(사용자에게 보이지 않음).
