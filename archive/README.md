# archive

현재 게임에서 쓰지 않고 보관만 하는 데이터입니다.

- `world_themes.js` — 동남아 외 지역 맵(한국 서울, 일본 도쿄, 미국 뉴욕, 프랑스 파리) 테마와 광고판 포스터.
  게임은 동남아 8개국(싱가포르·말레이시아·인도네시아·태국·베트남·필리핀·캄보디아·미얀마)만 스폰합니다.
  다시 넣으려면 `WORLD_THEMES` 항목을 `js/themes.js` 의 `THEMES` 에, `WORLD_BILLBOARD_POSTERS` 를 `js/config.js` 의 `BILLBOARD_POSTERS` 에 추가하면 됩니다
  (해당 모델은 `js/models.js` 에 그대로 있음).
